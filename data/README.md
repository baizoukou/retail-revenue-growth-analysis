# Dataset Information

For this project, I'm using the **Online Retail II dataset** from the UCI Machine Learning Repository. It contains approximately 1.07 million transaction records from a UK-based online retailer between 2009 and 2011.

I chose this dataset because it gives me the opportunity to work with real retail transactions and explore how data can help explain business performance.

My analysis will focus on sales trends, customer purchasing behaviour, returns, cancellations, and the factors contributing to revenue growth.

I'll also look at data quality issues, such as missing customer information and inconsistent transaction records, to understand how they might affect the results.

## Data Source

**UCI Machine Learning Repository — Online Retail II**

https://archive.ics.uci.edu/dataset/502/online+retail

## How I'll Manage the Data

I'll keep the original dataset in my local `data/raw/` folder rather than uploading it directly to GitHub.

The raw data will remain unchanged throughout the project. This will allow me to compare it with the cleaned data, check my results, and keep the analysis reproducible.

I'll document any changes made during cleaning so it's clear how the data was prepared before moving into exploratory analysis.
